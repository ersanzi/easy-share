## 用户可见增量

- 个人服务器云盘通过Windows CFAPI接入“此电脑”，根目录新建、编辑、粘贴、拖入后异步条件写回。
- 上传确认由独立服务器全文回读完成；未上传/冲突/占用/pin/部分正文保留，空闲缓存默认5分钟后自动回收，重开按需读取，复制出云盘才形成用户本地副本。
- 持久目录有稳定fileId和目录类型；列表、变更与缓存保护不把空目录误当普通文件。
- 正常退出保留CFAPI持久根和状态；恢复登录、前端显示、“此电脑”入口与托盘/悬浮窗空间一致。
- 悬浮窗“打开”走同一Shell入口，外部文件drop开启，上传状态在WebView2所属线程更新，不将文件投到局域网收件箱。

完整安全范围见 [Windows云端主存说明](../windows-cloud-primary.md)，当前接口与生命周期事实见 [架构](../architecture.md)。

## 兼容合并与新增回归

1. `DriveController` 的能力与持久目录接口、目录响应字段、空文件/缺对象预签重试配套合入最新版，而不是用旧文件覆盖。
2. 保留旧 `/mkdir` 和 `includeDirs` 尾斜杠展示；旧marker接入持久身份并去重，不能覆盖同名文件或在文件祖先下建目录。
3. 保留主窗口明确递归删除，已确认持久目录带fileId删除；子项到父项软删，普通正文保留在回收站，不被marker清理误删。CFAPI本机删除/改名仍不推断为远端操作。
4. 非Windows原 `spacedav` 认识持久目录类型并按子项优先删除，不把新的空目录当文件；原文件权限、上传/下载/移动通路保留。
5. 新增 `DriveDirectoryCompatibilityTest`、目录去重/类型冲突/递归顺序回归、Go目录类型与删除身份参数回归。
6. 活栈测试不再依赖本机检出目录名称，统一在当前检出的 `.rd-test` 新建随机根；祖先重解析或生产同步根拒绝。可显式传测试令牌，不读取运行AppData，默认关闭服务器/鼠标操作。
