# 2026-10-20 桌面端工作台改版（设备中继台）

用户要求：用 oil-ui 重新设计桌面端，参考钉钉/WPS 的设计语言，并明确「看不到他们的 UI 就说一声」。

## 取证与边界

- 本机 WPS 365 工作台（主窗 1707×1019）与钉钉 PC（主窗 1920×1032）都能还原抓图，已核对：WPS 白色卡片 + 顶部分页 + 64px 级文件行 + 彩色文件类型图标；钉钉蓝色顶栏 + 左栏文字导航 + 浅灰选中底 + 56px 级会话行。两家都只用主色标记主按钮与链接。
- 截图含公司文档名、同事姓名与签到位置，只做现场判断，不入库。可复算的 token 与尺寸继续以 [`docs/wps-dingtalk-ui-reverse.md`](../wps-dingtalk-ui-reverse.md) 为准。
- 视觉层没有上 REA：配色、圆角、字号不写在机器码里，而在 WPS 的 `.kuip` 明文资源与像素测量里；REA 用于逻辑、协议和状态机，不用来找视觉 token。本轮走资源 + 像素 + 实机抓图，和上一轮逆向结论一致。

## 设计方向

沿用上一轮方向卡 A「设备中继台」（见 [`design-notes.md`](../design/oil-ui-redesign/design-notes.md)）。首屏只回答两个问题：现在谁在线、正在交换什么。B 依赖当前数据模型没有的「最近材料」聚合接口；C 的深色与长时办公冲突，带宽曲线没有历史数据源。

## 实现

- [`frontend/src/App.vue`](../../frontend/src/App.vue)：工作台从「欢迎页头 + 系统状态卡 + 三张摘要卡 + 活动任务卡 + 共享卡」改为「状态带 + 附近设备/正在传输双栏 + 刚刚完成/共享与网盘 + 底部共享条」。设备行、任务行、待确认操作、失败入口、共享启停都接现有数据与动作；任务排序复用 `utils/tasks.ts` 的 `compareTasks`，与任务中心同序。
- [`frontend/src/style.css`](../../frontend/src/style.css)：新增 `--graphite` 与 `.relay-*`。局域网动作走石墨，云端动作走品牌蓝，主按钮只留一个。卡片改纯白 + 12px 圆角 + 一级阴影；页头 18→20px；侧栏选中态蓝色压深到 AA；顺带收口任务中心、网盘、听记、插件、设置页的旧对比度/小字问题。
- 未改各页业务组件、路由契约与 Core。

## 第二轮视觉收口（2026-10-20）

用户追问「渐变玻璃卡后续不要了吗」并要求继续找视觉可优化处。结论：Windows 内容层不再使用渐变玻璃卡；macOS 只保留窗口外壳的系统材质，不再用网页式大渐变。

### 改动

- 登录页：去掉蓝色渐变背景、悬浮玻璃卡和渐变图标，改为左侧平板品牌区（1px 网格）+ 右侧扁平表单；输入框白底、6px 圆角，主按钮只保留一个实心蓝。
- 设置页：640px 单列改为 1080px 双栏；账号/通用/共享在左，AI 工具连接/关于与更新在右。
- 知识问答：聊天卡从 420px 固定高度改为铺满视口；空态居中，提供 3 个可点击示例问题，点击后填入输入框并聚焦。
- 听记：记录卡铺满剩余高度，底部加「共 N 条听记」结束标记。
- 全局：主按钮、进度条、共享卡去掉渐变和内高光，改实色；渐变只保留在会议海报导出皮肤（导出件是另一产物，不在应用界面内）。
- 动效：工作台/登录卡/知识消息各加一段 160–200ms 淡入上移；按钮补按压反馈；沿用全局 `prefers-reduced-motion` 关闭规则。

### 证据

- `docs/design/oil-ui-redesign/shots/round3-final-v2/`：1440×900 最终视觉（登录、设置、知识、听记、工作台）。
- `docs/design/oil-ui-redesign/shots/round3-final-1180/`：1180×780 登录、设置、知识。
- `docs/design/oil-ui-redesign/shots/round3-interaction-final/`：知识问答空态 → 建议 → 提问 → 回答 + 引用，一次走通。
- 设计说明更新见 [`design-notes.md`](../design/oil-ui-redesign/design-notes.md)。

### 真机与构建

- 最终完整构建通过：`scripts/build.ps1` 的文档闸门、Go 测试、前端 57 tests、vue-tsc、Core、Wails、NSIS 全过；安装包 `build/bin/EasyShare-amd64-installer.exe`。
- 在 150% 缩放的 Windows 上启动最终构建：窗口 1180×780 逻辑像素（1770×1170 物理），工作台双栏完整、无横向溢出；首屏原生粗滚动条已改为 8px 细滚动条并下调页面 2px，最终画面无可见滚动条。
- 真机截图含当前账号与真实任务名，只保存在临时目录，不入库。
- 登录页真机未复验：应用保持已登录状态；登录页用同一份 Vue 源码在预览壳验证。
- 抓图踩坑：150% DPI 下普通 `PrintWindow`/屏幕坐标会按逻辑矩形裁掉右侧约三分之一，必须用 per-monitor v2 DPI 上下文取物理矩形再截；否则会把正常布局误判成溢出。
