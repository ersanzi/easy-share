# EasyShare 桌面端改版 · 方向卡（第 01 轮）

> 用 oil-ui 的方法重做桌面端外壳与**工作台**首屏，八个内置页与登录页沿用同一套语言。
> 证据：`baseline/` 八页现状截图；`refs/` 标杆真实画面；`preview/` 浏览器预览壳（打桩 Wails 绑定，跑真实 Vue 界面）。

## 认品类，拆标杆

**品类**：Windows 桌面端的「局域网直传 + 云盘 + 知识库」合一的工作客户端。用户日常来首屏做三件事：看现在有什么在传、把文件递给旁边那台机器、进网盘捞文件。

**标杆**（真实画面在本目录 `refs/`）：

| 标杆 | 图 | 拆出来的东西 |
| --- | --- | --- |
| 阿里云盘 Web 盘 | `refs/desktop/aliyun-desktop-film.jpg` | 左侧 180px 导航只放 6 个文字项、不加图标框；内容区顶部一行面包屑 + 视图切换 + 上传主按钮，下面直接是文件网格；没有页头口号。**基线**：导航窄、内容先行 |
| 百度网盘 | `refs/baidu.png`、`refs/baidu-download.png` | 品牌色 L≈62% 的亮天蓝（logo #2179f5 一带），图标圆底浅到几乎白；插画用玻璃拟态+气泡。**不沿用**：插画喧宾夺主，桌面工具里会显幼稚 |

留：窄导航 + 内容先行、外壳与内容分层、一个实心主按钮。
换：页头三行套话（"你好，欢迎回来"+副标题）→ 改成服务状态头；五块各讲一遍"运行中"的卡片墙 → 合并成一块；直白的方形按钮 → 项目 token 内的 6–8px 圆角。

## 调性（五个刻度，三个方向共用）

产品是内部工具，用户一天开八小时，装的全是同事发的文件与公司文档。

| 刻度 | 取值 | 依据 |
| --- | --- | --- |
| 能量 | 安静偏一点生气（强调色面积 ≤8%，只在主按钮、进行中进度、在线点） | 长时驻留的工作软件，喧闹会累 |
| 完成度 | 精致（1px 线、对齐到 4px 网格、阴影只用两级） | 竞品都是这等完成度，粗糙会掉信任 |
| 密度 | 中密（行高 44–56，信息一行内可读完，详情按需滑出） | 任务/文件列表要一眼扫十行 |
| 分量 | 中等偏轻（字重 400/500/600 三档，不用 700 大字压屏） | 工具界面要给数据让位 |
| 严肃度 | 偏庄重（圆角 8–14，无插画，动效 120–220ms） | 公司数据与法务场景，太活泼会显不专业 |

## 三个方向

### A · 设备中继台（推荐）
- **北极星**：这台电脑此刻在跟谁交换什么，一眼看完。
- **生成引擎**：把网络硬件控制台（中继器面板、交换机端口灯）的表达方式借过来——一行一台设备、带状态灯与正在跑的通道；只借"端口/通道"这一种手法。
- **首屏**：状态带（可被发现/共享/网盘，一行）→ 左「附近设备」列表 + 右「正在传输」列表（两列等宽，各占首屏 60% 高）→ 底部一条共享空间条。
- **字体**：系统无衬线，设备名 15/600、数据 12/500 用等宽数字；标题 20/600。
- **色彩**：白底 + #F8F9FB 外壳；石墨 #0F1115 作为设备行的标识色（与云盘页的蓝形成分工：局域网=石墨，云端=品牌蓝 #1F69E0）；在线点 #109968。
- **主视觉**：两列活数据本身；设备行左侧 36px 设备字形 + 状态灯。
- **图标**：线性 1.6px，只出现在设备类型和传输方向。
- **控件**：8px 圆角，按钮高 32，行 hover 用 6% 深色叠加；按下 scale(.98)。
- **结构性突破**：干掉"欢迎回来"页头，把服务状态压成一条状态带；首屏第一眼是"谁在线 / 在传什么"。
- **记忆点**：传输行的进度条末端有一个 2px 的流动光点，速度数字跟着跳。
- **放弃**：仪式感的口号、统计卡片墙、插画空状态。

### B · 侧栏工作台
- **北极星**：一台日常工具，打开就是昨天那摊活。
- **生成引擎**：桌面办公软件（WPS、钉钉 PC 版）的左栏工作台——左栏 264px 常驻，放常用入口 + 最近文件 + 设备，右侧内容是选中项。
- **首屏**：左栏（账号、快捷动作、最近文件 6 条、在线设备 3 条）| 右侧工作区（当前选中：任务/文件预览）。
- **字体**：正文 13，左栏条目 13.5/500，右侧标题 22/650。
- **色彩**：暖中性底 #FBFBF9 + 墨黑 #16181D；强调 #1F69E0 只在选中项；分隔用 #EDECE8。
- **主视觉**：左栏条目本身的排版（文件类型色块 20px）。
- **控件**：6px 圆角，选中项用左侧 2px 竖线 + 浅底。
- **结构性突破**：导航与内容是同一个"最近材料"列表，产品域只是过滤器。
- **记忆点**：选中一条时右侧内容从 8px 左侧滑入并淡入。
- **放弃**：图标轨 + 上下文面板的双层导航。

### C · 总览仪表
- **北极星**：今天这台机器的状态，像看仪表盘一样读完。
- **生成引擎**：克制版指挥中心——顶部一排 KPI、中部大图（网络拓扑或传输带宽曲线）、右列告警。
- **首屏**：KPI 条（4 个数）→ 左 2/3 带宽曲线 + 传输列表 → 右 1/3 告警与设备。
- **字体**：数字用等宽衬线感（ui-monospace + 字号 32/600），标题 15/600。
- **色彩**：深蓝黑底 #0E1420 + 冷白字 + 青绿 #14B8A6 强调；只在"正在进行"用一次暖色 #F0A83A。
- **主视觉**：实时的带宽曲线与端口占用条。
- **控件**：10px 圆角玻璃感面板、1px 亮边。
- **结构性突破**：整个产品首屏变成一张监控页，列表都成了配角。
- **记忆点**：曲线右端跟着新数据长出来的尖。
- **放弃**：白底办公软件的一概做法；深色在日常办公里费眼，作为反例候选。

## 推荐

**A**。它直接答首屏该答的问题（谁在线、在传什么），改动是可实施的外壳级重排而不是重写每页；B 的"最近材料"依赖一个当前数据模型里没有的聚合接口；C 的深色与长时办公冲突，且带宽曲线没有历史数据源。

## 第 02 轮落地（2026-10-20）

### 落地内容

- `frontend/src/App.vue`：工作台从「欢迎页头 + 系统状态卡 + 三张摘要卡 + 活动任务卡 + 共享卡」改为「状态带 + 附近设备/正在传输双栏 + 刚刚完成/共享与网盘 + 底部共享条」。设备行、任务行、待确认操作、失败入口、共享启停都接现有数据与动作；任务排序复用 `utils/tasks.ts` 的 `compareTasks`，与任务中心同序。
- `frontend/src/style.css`：新增 `--graphite` 与 `.relay-*`。局域网动作走石墨，云端动作走品牌蓝，主按钮只留一个。卡片改纯白 + 12px 圆角 + 一级阴影；页头 18→20px；侧栏选中态蓝色压深到 AA；顺带收口了任务中心、网盘、听记、插件、设置页的旧对比度/小字问题。
- 未改各页业务组件与路由契约，八个内置页与登录页沿用同一套 token。

### 边界

- 运行中的 easyshare 停在未登录页，本轮没有重启应用；视觉验证用同一份 Vue 源码 + Wails 打桩的浏览器预览完成，**真实 Wails 窗口的最终像素未复核**。
- 预览数据是打桩数据；「接收 / 另存 / 停止共享」只验证了按钮可见与绑定存在，没有验证 Core 状态变化。
- 钉钉顶部整条品牌蓝没有照搬：Wails 自绘 36px 标题栏更适合浅色外壳，蓝色只给主按钮与链接。
- 没有保留系统状态环形图与摘要卡墙：它们把首屏变成仪表盘，但用户每天来首屏真正要看的只有「谁在线、在传什么」。
- 空状态保留大面积留白。WPS/钉钉同样用留白而不是插画填满；只加 46px 圆形字形。
