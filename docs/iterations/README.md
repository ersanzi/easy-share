# 版本迭代记录

此目录用于保存每次版本迭代的独立记录，让需求、实现、验证和遗留问题可以追溯。

开始新版本前，先阅读：

- [版本迭代指南](../version-iteration.md)
- [当前架构](../architecture.md)
- [进度与路线](../progress.md)
- [开发指南](../development.md)

建议文件名使用 `YYYY-MM-DD-vX.Y.Z.md`；尚未确定版本号时可使用 `YYYY-MM-DD-topic.md`。

每份记录至少包含：

1. 目标与非目标；
2. 用户可见变化；
3. 设计与数据/API 变更；
4. 实现任务及状态；
5. 自动化测试与手工验收结果；
6. 已知问题、回滚方式和后续工作。

不要在此复制已经稳定的架构说明；稳定内容应更新到上级主题文档，并在迭代记录中链接它。
