| 根目录客户端 Go、`cmd/`、`internal/` | 桌面壳与 Core、账号与空间、CFAPI 挂载、身份/版本条件写回、缓存、Explorer 状态、桌宠及删除/撤销协调 |

| `deploy/ruoyi-db/` SQL | 与上述功能配套的兼容表结构和迁移（目录、版本、回收快照等）；不包含生产数据或凭据 |
