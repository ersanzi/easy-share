## 一句话

两个问题根因毫无关系。第一个是**配置迁移判据**漏了一种情况，第二个是**变量名拼错**导致地址压根没注入。

## 问题一：装完仍调本地地址

### 排查过程

先怀疑上轮的 CI 注入修复没生效——**这个怀疑是错的**：

| 检查 | 结果 |
|---|---|
| 本地 `go build -ldflags` 后扫二进制 | `47.96.128.231` 出现 3 次 ✅ |
| 本机已安装的 `E:\AAProgram\easyShare\easyshare.exe` | 也含公网地址 3 次 ✅ |
| `%LOCALAPPDATA%\EasyShare\config.json` | `"platformBaseUrl": "http://localhost:8090"` ❌ |

**地址烘焙得好好的，但根本没被读。**

### 根因

`internal/config/config.go` 的旧配置迁移：

```go
if strings.TrimSpace(value.PlatformBaseURL) == "" {
    value.PlatformBaseURL = defaultPlatformBaseURL
}
```

只有「字段为空」才填默认值。而早期 dev 版首次运行就把源码默认值 `localhost:8090` 写盘了（用户机器上那份时间戳 10-15 22:52），升级安装不清理该文件 → 字段非空 → 烘焙值被忽略。

**这个盲区此前没人看见，因为 CI 的断言只扫二进制**，看不到用户磁盘上已经躺着一份旧配置。流水线绿得很有底气，而包对老用户完全不可用。

### 修法

```go
if shouldRebasePlatformURL(value.PlatformBaseURL, defaultPlatformBaseURL) {
    value.PlatformBaseURL = defaultPlatformBaseURL
    saveUnlocked(path, value)      // 必须落盘，否则每次启动重判
} else if strings.TrimSpace(value.PlatformBaseURL) == "" {
    value.PlatformBaseURL = defaultPlatformBaseURL
}
```

判据**只允许单向迁移**：`loopback → 非 loopback`。三条边界各有理由，都写进注释：

| 情况 | 行为 | 为什么 |
|---|---|---|
| 存量 loopback + 烘焙外部 | **改写** | 早期 dev 留下的占位值，该改指服务器 |
| 存量 loopback + 烘焙 loopback | 不动 | 本地 dev 构建，否则会把本地配置改坏 |
| 存量已是外部地址 | 不动 | 用户手工填的，尊重它。换服务器要能单独做，不能静默发生在所有人机器上 |
| 存量为空 | 走原分支 | 不是这条路径的事 |

`isLoopbackURL` 解析失败时按「非本机」处理——宁可漏迁移，也不要拿坏地址覆盖用户配置。

## 问题二：macOS 打包失败

### 根因：变量名对不上

```
build-mac.yml:80   echo "EASYSHARE_LDFLAGS=-X ..." >> $GITHUB_ENV
build-mac.sh:14    PLATFORM_URL="${EASYSHARE_PLATFORM_URL:-}"
```

workflow 导出的名字，脚本读的是另一个。脚本永远拿到空值 → `LDFLAGS=()` 为空 → **Core 和 App 全都没注入地址**。

脚本只在 stderr 打了一行警告，而 stderr 在 CI 日志里没人看。构建本身一路绿灯。

### 教训（这轮最值得记的一条）

v0.3.1 失败在第 11 步「校验并整理产物」，断言报「未找到 PLATFORM_URL」。

**这个报错是正确且珍贵的——它抓到了真问题。** 我上一轮把它当成「断言写法有缺陷」（以为 macOS 的 `strings` 对 fat binary 只扫首个切片），于是去改断言。方向错了。

断言报红时先信断言，别急着怀疑检查手段。上轮那个 `lipo -thin` 改动本身无害、也确实更严（切片查能同时拦住漏注入和半注入，整文件 grep 拦不住后者），但它不是这次失败的原因。注释已改成真实理由。

### 顺带堵住静默通过

```bash
elif [ -n "${GITHUB_ACTIONS:-}" ]; then
  echo "错误: CI 中未设置 EASYSHARE_PLATFORM_URL，产出的包会指向 localhost:8090，不可发布。" >&2
  exit 1
fi
```

CI 里缺变量直接失败。本地开发仍允许不设——那正是「连本机 RuoYi」的正常用法，不该被这条拦住。
