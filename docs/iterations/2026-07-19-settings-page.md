# 设置页

日期：2026-07-19
阶段：阶段 2 — 系统托盘与设置

## 目标

为用户提供可视化设置界面，可修改设备名称、接收目录、共享目录和网络驱动器盘符，无需手动编辑 config.json。

## 设计决策

### 1. 暴露的配置字段

仅暴露用户可理解、可安全修改的字段：

| 字段 | 说明 | 交互方式 |
| --- | --- | --- |
| DeviceName | 设备在局域网中的显示名称 | 文本输入 |
| ReceiveDir | 接收文件的保存目录 | 目录选择器 |
| WebDAVRoot | WebDAV 共享根目录 | 目录选择器 |
| DriveLetter | 网络驱动器映射盘符 | 下拉选择（D-Z） |

端口、Token、DeviceID 等技术参数不暴露给用户（设计偏好：技术参数由引擎管理）。

### 2. 保存策略

- 前端收集修改后一次性提交 SaveSettings
- Go 端校验 → 写入 config.json → 通知 Core 重载配置
- Core 通过 /api/config/reload 接口热加载（如 Core 暂不支持则下次启动生效）
- 盘符修改需先取消旧映射再重新映射

### 3. 前端交互

- 侧边栏新增"设置"导航项，点击切换到设置视图
- 设置页使用 macOS 风格分组卡片（通用 / 网络驱动器）
- 目录选择调用 Wails 原生目录对话框
- 保存成功后显示短暂成功提示，2 秒后消失
