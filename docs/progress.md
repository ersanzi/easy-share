- **【已修复】「此电脑」云盘此前无法下载任何文件（2026-10-16）**：`readFile.Seek` 漏掉 `http.ServeContent` 的必需调用 `Seek(0, SeekStart)`，导致 WebDAV GET **一律 HTTP 500（`seeker can't seek`）**——双击任何云盘文件都打不开。上传/列目录正常，所以表面看不出。**修复后整份 GET 200 且完整、Range GET 206 且精确**（Range 顺带可用）。四条端到端用例（走真实 `webdav.Handler`）钉住；退回基线可复现失败。详见 [`known-issues.md`](known-issues.md) KI-9。
