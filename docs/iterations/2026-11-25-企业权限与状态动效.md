# 企业权限与状态动效

## 用户问题与范围

用户要求直接审查并实施企业权限加固，同时按“状态变化”梳理整个产品的动效：出现、消失、移动、变大小、换内容/图标、数字、按下、悬停、加载、完成和出错。要求解释变化、统一节奏、克制、可打断、长内容性能稳定并遵循系统减少动态效果。

本轮覆盖 Java 控制面、Go 桌面/Core/挂载缓存、Python 知识服务、Vue 主界面、Windows 桌宠/悬浮面板、三个内置插件及知识实验台/驾驶舱/WPS 页面。未发布版本、提交或推送。公司部署与真实多账号验收仍是独立交付步骤，不能由本地替身测试代替。

## 授权状态变化与实现

| 状态变化 | 原问题 | 当前行为 |
| --- | --- | --- |
| 有效账号 → 停用/删除/部门失效 | 旧角色、文件成员、登录态可能继续提供访问权 | 权限主体实时校验；失效主体不能由历史授权重新放行 |
| 部门管理员 → 管理范围变更 | 指定范围字段未完整加载；坏 ID 与超管目标边界不严 | 完整读取 specified 范围，支持本部门/下级/指定/全部；拒绝非法范围与子管理员修改超管 |
| 有角色 → 移除最后角色 | 重新落到缺行全开或旧的宽松逐账号配置 | 解绑前保存当前有效限制；明确空列表与缺失字段的区别 |
| 多人同时修改授权 | 整组替换与组织变化之间可交错；缺少可靠审计 | 数据库事务内串行授权写、主体/组织锁定、再次裁决及前后状态审计；锁冲突立即重试提示，审计失败回滚 |
| 仍是文件成员/上传者 → 空间撤权 | 文件级身份绕过已经撤销的空间权限 | 先验证空间访问，再裁决文件角色；旧上传者与显式成员也失效 |
| 权限端点正常 → 故障/字段异常 | 桌面和知识服务曾全开放行 | 只有有效主体与明确布尔授权可用；失败收起入口，服务端拒绝访问 |
| 企业管理员 → 降权 | 同名知识本地档案保留旧管理员角色 | 请求身份使用当前控制面角色；逐请求核验，无 60 秒正向授权缓存 |
| 云任务账号 A → 账号 B | 旧文件名/路径、修改与删除可跨账号访问 | Core 生成并验证归属，列表/事件/操作隔离；旧云任务不认领，隐藏历史仍保留已记录下载路径归属 |
| 高频云进度 → 慢控制面 | 逐条验权积压旧进度并堵住 LAN | 按任务合并、容量 64、每批实时验权且至少间隔一秒，设备事件独立交付 |
| 登录 → 退出/快速换号 | 迟到登录、401、JSON、文件下载可能污染新会话 | 会话世代与条件提交/注销；响应写出前复查，旧流中止而非作为完整文件交付 |
| 文件可见 → 撤销且只拉增量 | 旧缓存残留文件名；日志分页/裁剪水位可能跳过变化 | 共享增量明确 reset 后实时过滤全量；个人缓存绑定令牌，日志断档重建，分页水位只到实际交付事件 |
| 授权列表缺字段/null → 请求提交 | 省略部门列表可能被当作全员可见 | 缺字段/null 拒绝；只有明确 [] 才清除部门限制并恢复继承 |
| 管理表加载/保存 → 失败 | 空白被误读为无成员，点击轮转角色意图不清，重复/旧响应覆盖 | 明确选择后保存；撤权有确认；保留失败草稿；写成功但重读失败要求核验；保护进行中的提交 |

## 按状态变化的动效审查

| 状态变化 | 统一处理 | 行为和性能约束 |
| --- | --- | --- |
| 出现/消失 | 弹层、菜单、抽屉、阅读/预览、提示使用语义过渡 | 进入 200ms、退出 120ms；离场立即 inert，不让旧按钮继续收键盘/鼠标 |
| 连续开/关与反向 | 活动抽屉和确认框复用同一节点；内容淡入从当前透明度接续 | 中断不排队、不叠实例；关闭和业务状态不依赖动画结束 |
| 页面/标签/内容/图标替换 | 保持容器结构，只对必要内容作短淡入 | 最新操作立即生效，不保留旧敏感内容等待离场；异步响应校验当前上下文 |
| 数字与进度 | 等宽数字；固定宽度的 scaleX 进度 | 不动画 width/height；高频进度不重建整张任务表 |
| 按下/悬停/焦点 | 共用 120ms 反馈及统一曲线 | disabled 不施加按下位移；键盘焦点清楚，弹层循环与返回焦点可用 |
| 加载 → 完成/错误 | 保留可理解的加载文案、按钮忙碌状态和失败恢复 | 防重入，保留编辑草稿；搜索/预览/会议旧响应不能替换新选择 |
| 拖动/缩放/窗口调整 | 直接随输入更新，不添加追赶动画 | 脑图无默认空间补间；拖入子元素不闪烁；窄窗口无横向溢出 |
| 长列表持续更新/滚动 | 稳定任务对象 + v-memo；屏外延迟渲染保留固有高度 | 首 24 行正常渲染，旧浏览器 feature detection 回落普通列表；Tab 能跨越边界 |
| 系统偏好改变 | CSS 与 JS 动态响应；Windows 原生浮层跟随系统客户端动画开关 | 减少动态效果时无空间位移/旋转/进度补间，仍有静态状态与短淡入 |

节奏集中在 `frontend/src/style.css`：反馈 120ms、进入 200ms、退出 120ms、进度 180ms、减少动效淡入 80ms；常规曲线 `cubic-bezier(0.2,0,0,1)`，退出 `cubic-bezier(0.4,0,1,1)`。静态页面使用相同 token，不新增动画运行时依赖。去掉交互入口的单向关键帧、transition:all、进度宽度插值、录音持续闪烁及全局极短时长“关动画”补丁。

关键实现：`frontend/src/directives/contentMotion.ts` · `animateContentChange` / `presenceMotion`；`frontend/src/composables/useEasyShare.ts` · `retainTaskRows`。静态导出海报保持静态，仅父级预览反馈变化，避免把导出内容和交互动效耦合。

## 实测与回归

2026-11-25，Windows 本机，Edge 158.0.4370.33，1440×960，真实 Vue 源码 + 独立 Wails 接口替身。接口替身不连接真实控制面。样本包含千条任务、16 条进度动画，以及滚动和真实前端任务事件；各测量单独记录布局和主线程脚本耗时。

第一次真实事件/滚动 p95 约 49.9ms，暴露长列表更新成本；仅加 v-memo 仍约 30ms。补稳定行身份和屏外延迟渲染后：

| 2 秒采样场景 | p95 帧间隔 | 最大间隔 | 布局次数/耗时 |
| --- | --- | --- | --- |
| 千行列表、16 条进度 | 10.1ms | 50.1ms | 0 / 0ms |
| 千行列表滚动与任务事件 | 10.2ms | 120ms | 11 / 5.87ms |

原始报告：[状态动效实测 JSON](2026-11-25-状态动效实测.json)。出现过单帧尖峰，不能据 p95 宣称绝无掉帧；随后对每个场景延长到 5 秒：两项 p95 均为 10.1ms，进度布局仍为 0，滚动/事件布局 33 次共 18.73ms；主线程 Long Tasks 均为空，但最大帧间隔仍分别为 50.1ms / 120.1ms，保留为未消除的尾部尖峰，不推断具体原因。[延长采样 JSON](2026-11-25-状态动效长采样.json)同时保留，未只挑最好一次结果。最终源码复跑的 5 秒采样 p95 均为 10.2ms，最大间隔 50.1ms / 130ms；130ms 位于滚动开始第 3 帧，主线程 Long Tasks 仍为空，不把尖峰归因于未经证明的原因。[最终报告](2026-11-25-状态动效最终实测.json)记录逐个慢帧时间点。无页面异常；连续反向/离场隔离、确认框键盘循环、快速页面选择、动态减少动效、1024×720 抽屉边界及屏外行 Tab 导航通过。另人工浏览主界面各主页面，未发现根节点横向溢出；未做安装版 WebView2、原生桌宠动画或真实 WPS 宿主的视觉验收。

## 兼容、迁移与发布边界

1. 先备份数据库、暂停旧授权写入口，执行 `deploy/ruoyi-db/easyshare-permission-hardening.sql`，再升级所有控制面实例、知识服务及桌面端。新增 `es_permission_write_guard` 与 `es_permission_audit`；迁移已接入投递脚本。不得混跑旧授权写协议。流程见[控制面部署](../../deploy/ruoyi-db/README.md)。
2. 共享增量响应新增明确重建标记，个人分页水位修正；旧客户端收到业务失败后需回退全量。新增内部任务归属校验端点与账号请求头；任务增加可选 ownerId/hidden，旧云任务无归属时拒绝认领。公开 Wails 方法签名未变，已重新生成包含任务新字段的绑定，并同步前端类型。用户配置与发布版本不变。
3. 回退时保留新增表、审计和用户数据；旧服务会恢复本次修复的授权漏洞，不能把它作为故障时静默放开的兜底。
4. 权限角色仍是并集，无配置的新有效账号仍按既有策略全开；移除文件显式成员回到继承。UI 区分直接授权和继承提示，不能把服务端没有返回的有效权限伪装成已知。
5. 已下载文件与旧预签名 URL 不会被追溯撤回；审计为事务记录，尚无独立审计检索 UI/防数据库管理员篡改能力。
6. 企业模式关闭本地 lab/debug 调试通道，避免它们直接枚举索引形成旁路；WPS 登录转发企业认证，退出调用新注销端点。密码代理尚未适配控制面的额外验证码/加密挑战，需要按真实控制面策略部署验收，不会自动关闭安全策略。桌面知识退出只解绑本地，不撤销共享企业令牌。
7. 实时 SSO 与共享全量列举增加服务端请求成本，尚未做组织规模压测。投产前须用专用多账号验证撤权/降权/停用/故障、增量重建和并发授权，确认权限审计落库及新旧实例升级顺序。
