# EasyShare 桌面端企业化整改 · 第二轮

> 承接[第一轮](2026-10-26-桌面端企业化整改-第一轮.md)（插件页裸奔、知识服务地址对账）。本轮做用户实机反馈的另外两条：**账号头像/昵称不能改**、**缺少细致的权限管理**。
> 模型由用户拍板：权限 = **功能权限矩阵**（五项能力按人开关）；个人资料 = **昵称 + 头像 + 修改密码**。

## 用户问题

用户原话（四条反馈里的后两条）：

- 「账号信息，头像和名称不能更改。」
- 「缺少细致的权限管理。」

产品预期是「企业来使用，可以有知识库，内网传输，问 ai」——企业场景下，谁能用哪块能力必须由管理员说了算，而不是全员全开。

## 目标

1. 成员能自助改昵称、头像、密码，不用找管理员、不用改数据库。
2. 超管能按人配置「知识问答 / 会议听记 / 网盘 / 共享空间 / 插件中心」五项能力：关掉的入口在桌面端隐藏，**并且服务端真的拦住**（不是藏个按钮）。

## 非目标

- 不做角色/岗位自定义、不做新的文档级 ACL（文档级可见性此前已有 `es_file.visible_depts`，不属本轮）。
- 不改插件商城的匿名访问模型（决策与后续见「已知边界」）。
- 不重构知识服务本地账号体系——桌面知识会话改走控制面 SSO 是下一片。

## 设计决策

### 1. 权限模型：五项功能开关，缺行 = 全开

- 表 `es_user_permission`（`deploy/ruoyi-db/easyshare-user-permission.sql`），一行一账号。**刻意不写默认行**：新账号、存量账号都靠「缺行即全开」得到开箱可用，只有管理员真正关过某项的账号才落行，存量零迁移。
- drive 关闭时 shared 一并失效（`FeaturePermissionService.sharedFeatureEnabled`）：共享空间是网盘的一个空间，管理员不必连关两项。
- 矩阵不覆盖管理能力本身：`/easyshare/permission/*`、`/system/user/*` 不在开关管辖内，管理员即便关掉自己某项也能回管理页改回来，不存在「把自己锁在门外」。
- 五项口径：knowledge（问答与入库）、meeting（听记与纪要）、drive（个人网盘）、shared（共享空间）、plugin（插件中心）。

### 2. 强制点：一处裁决，控制面 + 知识服务两层落地

控制面 `FeaturePermissionService.enabled` 是唯一裁决点（`platform-drive/.../service/FeaturePermissionService.java`）：

- **网盘**：`DriveFeatureInterceptor` 由 `DriveWebConfig` 挂到 `/easyshare/drive/**`。按路径一次覆盖而不是逐个方法加注解——网盘入口二十多个、以后还会加，新增端点自动受管。未登录放行给 `@SaCheckLogin` 回 401：这里若抢先返回 403，会把「没登录」误导成「没权限」。
- **共享空间**：`SpaceService.sharedPermissionOf` / `checkSharedWritable` / `checkSharedReadable` 三处收口；`SpaceController.mine()` 在 drive 关闭时直接返回空列表，客户端登录后不再挂共享盘。
- **知识服务**：`knowledge/app/main.py` 的 auth 中间件按 `_FEATURE_PREFIXES` 校验——`/documents`、`/query`、`/ingest`、`/lab/api/uploads` 归 knowledge，`/meetings` 归 meeting，命中且身份来自控制面 SSO 时回 403「该功能已被管理员关闭，请联系管理员」。

知识服务的 features 由 SSO introspection 顺带取回（`knowledge/app/auth/sso.py` · `_feature_flags` 调 `GET /easyshare/permission/mine`，随 60s 缓存）。**取不到时 fail-open 并告警**：身份已经验过，为一次附加查询把所有人挡在门外，代价远大于收益。

### 3. 个人资料：昵称/密码走标准通道，头像自建

- 昵称、密码走 RuoYi 标准个人中心 `/system/user/profile` 与 `/system/user/profile/updatePwd`——任何登录用户都有权改自己，无需扩展表。
- 头像**不用** `sys_user.avatar` + `sys_oss`：标准上传接口要求 `system:oss:upload` 权限、普通成员没有，且控制面只配了 EasyShare 自己的 RustFS。改为自建 `es_user_profile(avatar_mime, avatar_data BYTEA)`（`deploy/ruoyi-db/easyshare-user-profile.sql`）——一张 ≤2MB 的图、一人一行，规模上不是问题，部署只多一条 DDL。
- 读头像 `GET /easyshare/profile/avatars/{userId}` **匿名**（`@SaIgnore`：`<img>` 发不了 Authorization 头），7 天缓存 + `?v=` 版本参数避免换头像后看旧图；MIME **按文件头嗅探**、拒绝 SVG（可内嵌脚本）。
- 写头像 `POST` / `DELETE /easyshare/profile/avatar` 要求登录本人，2MB 上限两侧一致（Go 侧提前拒，省得白传）。

### 4. 桌面端：权限态生命周期与入口显隐

- `AuthUser` 增加 `userId` 与 `features`；`App.syncAccountProfile` 在**账号登录成功 / 启动恢复会话 / 后台校验刷新**三处拉取 features 与头像地址，写回会话与 `App.features`。
- 拉取失败 → 五项全开（`account.AllFeatures()`）：旧版控制面没有接口、或一次网络抖动，不该把入口全藏起来；真正拦截在服务端。
- 登出清空 features；管理员改自己权限后立即 `RefreshProfile()`，入口当场变化；`auth:user-updated` 事件让前端 `syncAuth()` 重取。
- 新增绑定：`UpdateNickName` / `ChangePassword` / `UploadAvatar`（系统文件对话框，取消按原样返回当前态）/ `RemoveAvatar` / `RefreshProfile` / `AdminPermissionList` / `AdminSavePermissions`。
- 前端只做入口显隐（`frontend/src/App.vue` · `sectionVisible`/`sectionHome`：知识域只开会议时落到会议页；`SettingsPanel.vue` 的账号、共享、插件卡片同口径）。代码与文档都写明：**藏按钮不是鉴权**。
- 管理页新增「权限」Tab（`frontend/src/components/AdminPanel.vue` · `permissionRows`），一行一账号五个开关；共享空间开关在网盘关闭时禁用；显式行与「缺行全开」在客户端合并渲染。

## 兼容与迁移

- 两条新 DDL 均 `CREATE TABLE IF NOT EXISTS`，纳入 `scripts/ship-control-plane.ps1` 的 `$easyshareSql`，每次投递重放，新服务器建表、存量服务器自动补。

## 已知边界与后续切片

1. **桌面端知识会话仍是本地账号**：桌面「知识」页登录走知识服务自己的 `/auth/login`（本地用户库 + 本地令牌），而知识服务的功能拦截只对控制面 SSO 令牌生效。因此 knowledge / meeting 两项在桌面端**目前只有入口显隐，服务端强制没有闭环**。下一片：Core 用控制面令牌直接调知识服务 SSO（`Authorization: Bearer <控制面令牌>`），桌面不再要求二次输入知识账号口令；落地后矩阵对桌面同样强制。
2. **插件中心是匿名商城**：`/easyshare/plugins` 匿名可读、安装包 SHA256 校验，矩阵只控制客户端入口显隐。若企业要求「未授权不能安装」，需要把商城读接口改为登录 + 校验 plugin 开关——涉及未登录时的商城体验，单开一片。
3. **知识服务 fail-open**：控制面权限端点不可用时按全开。若企业要求 fail-closed，需要把降级策略做成部署级配置，并接受一次控制面抖动导致全员 403。

## 真机点验清单（下次省事）

本轮改动需要控制面重部署 + 桌面端重装才能端到端可见，尚未真机点验。建议按此顺序：

1. 设置页改昵称 → 顶栏与托盘同步；重启后仍是新昵称。
2. 上传头像 → 立即显示；重启后仍在（登录时 `syncAccountProfile` 重取）；移除后回落昵称首字。
3. 修改密码 → 退出 → 用新密码登录成功；旧密码被拒。
4. 管理页关掉某账号「网盘」→ 该账号重登后侧栏无「网盘」，直接带令牌请求 `/easyshare/drive/objects` 返回 403。
5. 只关「知识问答」、保留「会议听记」→「知识」域落到会议页，问答入口消失。
6. 关「插件中心」→ 侧栏「扩展」消失；设置页插件管理卡隐藏。
