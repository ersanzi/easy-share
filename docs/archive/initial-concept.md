### 一、 架构设计：前后端分离

软件启动分为两个进程空间：

1. **UI 进程**：负责登录框、设置页、传输列表的展示。使用 Vue3 编写，响应速度极快，动画流畅。
2. **Core Service (Go)**：在后台运行，即使关闭窗口，核心服务（如局域网传输、磁盘挂载）仍可保留。

#### 目录结构

```
EasyShare/
├── app.go              # Wails 主入口，绑定 Go 方法给前端
├── main.go             # 程序启动入口
├── internal/
│   ├── cloud/          # 云盘逻辑（上传、下载、断点续传）
│   ├── lan/            # 局域网逻辑（UDP发现、TCP高速传输）
│   └── drive/          # 虚拟磁盘逻辑（WebDAV服务）
├── frontend/           # 前端代码目录
│   ├── src/
│   │   ├── views/      # 页面（登录、主页、传输列表）
│   │   ├── components/ # 组件（漂亮的按钮、进度条）
│   │   └── assets/     # 样式和图片
│   └── wailsjs/        # 自动生成的Go调用桥接文件
└── build/              # 打包配置
```

### 二、 功能模块详细设计

#### 1. "我的电脑"显示方案 (优雅的 WebDAV)

为了不写复杂的 C++ 驱动，我们采用 **映射网络驱动器** 的方式。

- **原理**：Go 启动一个本地 WebDAV 服务（监听 `127.0.0.1:19080`）。
- **实现**：软件安装/启动时，执行静默命令：`net use Z: http://127.0.0.1:19080 /user:User Password`。
- **效果**：用户在“我的电脑”看到 Z 盘，图标可以是自定义的（需配置 `.ico` 文件），体验与 WPS 云盘几乎一致。

#### 2. 局域网传输 (性能核心)

- **发现**：UDP 广播心跳包。
- **传输**：基于 TCP 的 **零拷贝** 传输。Go 的 `io.Copy` 可以直接在 Socket 之间搬运数据，不经过用户态内存，CPU 占用极低，速度跑满千兆网卡。
- **交互**：前端点击“发送文件” -> 调用 Go 的 `DiscoverPeers()` -> 前端展示在线用户列表 -> Go 建立连接传输。

#### 3. 云盘存储

- **分块上传**：大文件切分为 5MB 的小块并发上传，避免超时，支持秒传（计算 MD5）。
- **数据库**：本地使用 SQLite 记录文件映射关系，云端使用 PostgreSQL。
