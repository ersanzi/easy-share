# BM25 检索降级：Embedding 故障时核心检索不中断

> 里程碑 1.9 第二切片（TDB-AM 对标 P0-3）。开工/完成：2026-08-20。

## 用户问题

Embedding 供应商 API 故障时 `/query` 直接 500，检索服务整体不可用——外部依赖单点拖垮核心能力。

## 设计决策

- 降级点选在 `Retriever.retrieve` 的 **embed 调用异常**：捕获后自动转 BM25 关键词检索（索引懒构建，与向量库记录数不一致时重建，自动跟随文档增删）；未注入 BM25 时保持原行为（异常上抛）。
- 未配置 Embedding 的离线场景已由 HashEmbedder 覆盖（不抛错），不属本切片范围。
- 生产装配（`services.py`）与测试装配（`helpers.py`）同步注入 BM25，环境一致。
