## 1. 背景与目标

公司部署两周观察期（[company-rollout-guide.md](../company-rollout-guide.md)）需要一个
周期决策输入：使用率是否起来、同事在问什么、哪些问题查不到、生成质量如何。
数据源 2026-09-01 生产检索回灌时已贯通（`QueryLog`），此前只有驾驶舱
`stats()` 全时段/混合口径（30 天窗口还只作用于其中一个指标），缺一个
**严格窗口化、可直接发给人看**的周期报告。完成标准：脚本可跑 + 空数据兜底 + 回归绿。

## 2. 实现

| 位置 | 内容 |
| --- | --- |
| `app/kb/query_log.py` | 新增 `windowed_stats(days, now=None)`：全部指标严格限定最近 N 天（总查询/检索生成拆分/活跃天数/平均结果数与 top 分数/零结果数/策略分布/高频引用文档 Top5/去重盲区/生成质量）。驾驶舱 `stats()` 不动，互不影响 |
| `app/kb/weekly_report.py`（新） | 纯格式化模块 `build_weekly_report()`：五节中文周报（使用率/检索命中/盲区/生成质量/观察提示）；时间按 UTC+8 显示（固定偏移，无 tzdata 依赖）；空数据兜底文案；「观察提示」只由事实触发简单规则（日均<3 次、盲区占比>30%、忠实度<0.7），不下结论 |
| `scripts/weekly_report.py`（新） | CLI：`--days`（默认 7，两周观察用 14）、`--db`（默认 .env 的 `QUERY_LOG_PATH`）、`--output`；只读不改状态；库文件不存在时 stderr 提示并输出空数据周报 |
| `tests/test_weekly_report.py`（新） | 4 用例：空库兜底 / 有数据汇总断言 / 窗口过滤（now 注入前推）/ 盲区去重与阈值提示 |

## 3. 冒烟与发现

- 空库路径：库不存在 → stderr 提示 + 空数据周报（exit 0）；开发机 `data/query_log.db`
  最后写入 7 月底（旧冒烟数据），14 天窗口正确判空。
- 有数据渲染：策略分布、高频引用、去重盲区、生成质量、低使用率提示均正确输出。
- **顺手修一处误导标签**：向量检索恒返回 top_k 条（零分也计数），盲区条目原先
  标「[5 条结果]」——改为「[低分 <score>]」（`result_count>0` 时按分数表达）。
- 部署机用法（观察期）：`python scripts/weekly_report.py --days 14`，或
  `--output 周报.txt` 留档对比逐周趋势。
