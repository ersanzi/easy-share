# EasyShare 同事上手指南（发群版）

> 面向使用 EasyShare 的同事，一页纸讲完。管理员/IT 视角的部署与分发见
> [`company-rollout-guide.md`](company-rollout-guide.md) 与 [`../deploy/server-linux/README.md`](../deploy/server-linux/README.md)。
> 最后更新：2026-09-06（v0.2.0）

## 安装（约 1 分钟）

1. 拿到安装包 `EasyShare-amd64-installer.exe`（IT 发在群里或网盘共享）。
2. 双击安装。**如果 Windows 弹蓝色提示"Windows 已保护你的电脑"**：点「更多信息」→「仍要运行」——因为安装包没买代码签名证书，系统对内部软件都会这样提示，属正常。
3. 安装过程会问两个问题，都建议选「是」：
   - **开机自动运行**：选了以后开机即有 EasyShare，接收文件不漏；
   - **放行防火墙**（要管理员确认一次）：不放行的话，局域网互传会搜不到同事的设备。
4. 装完桌面有 EasyShare 图标，双击打开。

## 登录（约 10 秒）

- 账号密码找 IT 开通（第一次联系 IT，之后在客户端「设置 → 管理页」里管理员也能开）。
- 登录一次即可：公司服务器地址、知识库地址都已自动配置好，不需要填任何 IP 或端口。
- 登录失败先看提示：写着"无法连接账号服务 + 服务器地址"说明是网络问题（没连公司网络/VPN），重试；提示账号或密码错误就找 IT 重置。

## 日常怎么用

| 想做什么 | 怎么做 |
| --- | --- |
| 传文件给同事 | 把文件**拖到任务栏托盘图标上**（悬浮窗要固定住才能接拖放），选对方设备即可；同一局域网内秒传 |
| 存到公司网盘 | 左侧「网盘」页上传；或拖文件到悬浮窗选网盘；装完后在资源管理器「此电脑」里还有个人网盘和共享盘入口 |
| 问公司知识库 | 左侧「知识」页直接提问，答案带出处；服务器地址和账号已自动填好，首次只需输密码 |
| 随时全局搜索 | 按 **Alt+Space** 呼出快捷搜索，知识和网盘文件一起搜，回车直接打开 |
| 找刚才复制过的内容 | 按 **Win+V**（或面板提示的实际热键）打开剪切板历史，选中即自动粘贴 |
| 文档里查知识 | 装了 WPS 的同事可让 IT 跑一次 WPS 插件安装脚本，之后 WPS 文字里选中段落点「查知识」 |

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 局域网互传搜不到对方 | 多半是防火墙没放行：Windows 设置 → 防火墙 → 允许应用通过防火墙，勾选 EasyShare Core（专用网络）；或重装一次安装包选「放行」 |
| 登录提示无法连接 | 确认接入公司网络/VPN；提示里的服务器地址原样发给 IT |
| 360/火绒/Defender 报警 | 内部软件未做商业签名可能被误报，选「信任/允许」即可；企业版杀毒请 IT 在控制台统一加白 |
| 想更新版本 | 不用手动装：应用启动后会自动检查新版本并提示，一键升级 |
| 卸载会删我的文件吗 | 不会。卸载只删程序本身，接收的文件、配置、日志都保留（卸载完成时有具体路径提示） |
| 文件放在哪了 | 默认在「下载」目录的 EasyShare 子目录，可在「设置」页改 |

## 给 IT 的三句备忘

1. 分发前先在公司服务器上完成部署与账号开通（见 `deploy/server-linux/README.md`），并用 `build.ps1 -PlatformUrl http://<服务器IP>:8090` 构建公司版安装包；
2. 杀毒软件企业控制台把安装包与 `easyshare.exe`/`easyshare-core.exe` 加白，减少员工侧弹窗；
3. 后续版本升级走在线升级通道（`publish-release.ps1`），同事端自动更新，无需再发安装包。
