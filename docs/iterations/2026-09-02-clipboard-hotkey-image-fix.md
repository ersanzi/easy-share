# 剪切板插件真机修复 — 热键冲突回退链 + 微信 24bpp 图片损坏

## 用户问题（2026-09-02 真机反馈）

1. **快捷键失效**：按 Win+V 没反应，怀疑被别的软件占了；不行就换个快捷键。
2. **图片损坏**：从面板里复制粘贴图片出来是坏的（斜条纹、颜色错乱）。

## 根因

### 热键：静默回退到 Ctrl+Shift+V，用户不知情且回退键本身是高频冲突键

`desktop.log` 实锤：`panel: 全局热键 Ctrl+Shift+V`——Win+V 与 Win+Shift+V 在真机上都被占用（Win+V 被 Windows 自带剪贴板历史占据），回退链落到 **Ctrl+Shift+V**。两个问题：

- 静默回退无任何用户可见信号，用户仍按 Win+V →「失效」。
- Ctrl+Shift+V 是浏览器/Office/编辑器里「粘贴为纯文本」的高频快捷键，全局 RegisterHotKey 会把它从所有应用手里抢走——回退键本身成了新的冲突源。

### 图片：微信以 24bpp DIB 放图，解析按紧凑行读，丢行尾对齐填充

损坏 PNG 全部 `source=Weixin.exe`。DIB 规定每行按 4 字节对齐（24bpp 行尾最多 3 字节填充），`dibToPNG` 的 24bpp 分支按 `w*3` 紧凑取行 → 每行漂移 1–3 字节 → 斜条纹 + BGR 通道错位（彩虹纹）+ 整体倾斜。数值验证：825 宽（行 2475→2476，每行差 1 字节）× 980 行累计漂移 245px ≈ 14°，与视觉观测吻合；1350 宽差 2 字节/行，倾斜更重，亦吻合。32bpp 行天然 4 对齐无此问题（历史记录里截图类不损坏、只有微信损坏的原因）。

## 修复

| 位置 | 改动 |
| --- | --- |
| `internal/clipboard/listener_windows.go` | 24bpp 分支按对齐跨距取行：`stride := (w*3+3)&^3`；长度校验改为 `offset+stride*(h-1)+w*3`（末行不强制带填充，兼容省略尾部填充的生产者） |
| `panel_windows.go` | 回退链重排：**Win+V → Win+Alt+V → Ctrl+Alt+V → Alt+Shift+V**（剔除实测被占的 Win+Shift+V 与高频冲突的 Ctrl+Shift+V/Alt+V）；回退发生时打明确告警日志；注册到的热键以 `&hk=` 参数随面板 URL 下发；全部失败也记日志 |
| `panel_windows.go` | `Navigate` 从 `embedWebView` 挪到热键注册之后（URL 需带上热键参数；窗口初始在屏幕外，时序无感） |
| `plugins/clipboard/index.html` `app.js` | 面板底部脚注新增「{hk} 唤起」提示（无参数时隐藏，纯浏览器调试不受影响） |
| `plugins/clipboard/manifest.json` | 2.0.1 → 2.0.2，描述注明自动回退与面板底部展示 |

## 设计决策

- **换链不换首选**：Win+V 仍是首选（系统剪贴板历史关着的机器上直接顶替，正是产品意图）；回退链避开一切高频组合。Win+Alt+V 无已知系统/主流软件占用，作为首选回退。
- **可见性优于可配置**：不引入热键设置项（用户不该做技术选择），改为把实际生效热键透出到面板底部 + 告警日志，静默回退不再让用户摸不着头脑。
- **只修 24bpp 跨距，不动 32bpp**：32bpp 行恒 4 对齐，`w*4` 即正确；alpha 全 0 兜底已有单测覆盖（本次补齐）。

## 验证

- 单测 `internal/clipboard/dib_windows_test.go`：24bpp 宽 5（1 字节填充）bottom-up/top-down 全像素校验 + 32bpp alpha 全 0 兜底——修复前必红（填充字节放垃圾 0xEE）。
- 全量 `go test ./...` 绿；`wails build` 过。
- 真机端到端（安装版 E:\AAProgram 已部署）：
  - 日志出现 `Win+V 被占用（Windows 剪贴板历史或其他软件），全局热键回退为 Win+Alt+V`；
  - Win+Alt+V 弹出面板，底部显示「Win+Alt+V 唤起」，Esc 关闭；
  - 合成 24bpp 带填充 DIB（101×80，模拟微信形态）入剪贴板 → 落盘 PNG 8080 像素与公式全对；
  - 新构建下真实微信截图（1920×1031）落盘无斜纹/错位（视觉模型复核）。
- 部署注意：已安装插件 `builtin=false` 不吃 embed 种子，手工同步了 `%LOCALAPPDATA%\EasyShare\plugins\clipboard\` 三文件并把 `plugins.json` 版本改 2.0.2。
