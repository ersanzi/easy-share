# 迭代：会议听记·图文海报模板（内置主题）

- 日期：2026-10-12
- 状态：已完成（当日真机验收通过）
- 关联：[`2026-10-12-思维导图与导出.md`](2026-10-12-思维导图与导出.md)（上一片把「图文模板（VIP 海报风）」列为暂缓大件，本片拉起；用户拍板：不考虑 VIP，内置一些即可）

## 目标 → 机制

| 目标 | 机制 |
| --- | --- |
| 像钉钉听记一样把纪要变成可分享的海报图 | 前端把 summary（纪要/要点/待办）渲染成 720px 宽单页长图 DOM，html2canvas 截图导出 PNG |
| 多套视觉风格 | 纯 CSS 变量主题皮肤，5 套内置（经典/碳素/极光/蓝图/暖纸），零图片资产 |
| 保存 / 直接粘贴发送 | html2canvas `scale:2` → Blob → `a.download` 落盘；复制走 `navigator.clipboard.write(ClipboardItem)` |

## 实现

- **`frontend/src/components/MeetingPoster.vue`（新增）**：海报组件。`summary` 双形状归一为统一展示小节（模板 `sections[]` ↔ 默认模板 `minutes`/`key_points`），待办渲染为 checkbox + 负责人/期限 tag；头部含品牌行、标题、日期/时长/发言人数、已改名的发言人名单（默认「说话人 N」不占版面）。
- **`MeetingsPanel.vue`**：详情操作行加「图文海报」按钮（仅 completed 可点）；弹窗 = 主题磁贴组 + zoom 缩放预览 + 保存/复制动作。**截图走离屏全尺寸实例**（弹窗预览实例经 CSS `zoom` 缩放，不能直接当 html2canvas 截图根，故同一组件渲染两份：预览份 + `position:fixed; left:-2400px` 截图份）。html2canvas 动态 `import()`，自动拆 chunk（201KB），不打开弹窗不加载。
- **`style.css`**：海报皮肤全部走 `--p-*` CSS 变量；**刻意只用 html2canvas 支持的特性**——hex/rgba 颜色 + `linear-gradient`，不用 `oklch`（Tailwind 4 默认色域，html2canvas 解析不了）与 `box-shadow`（被忽略），卡片质感用描边 + 色块表达。

## 验证

- vue-tsc + vite build 全绿；`wails build` 重建桌面壳（纯前端切片，Go/Python 零改动）。
- 真机（安装版覆盖重启，computer-use 全流程）：登录 → 会议听记 → 产品周会详情 → 图文海报弹窗 → 经典/碳素/蓝图三主题即点即切 → 保存图片两次落盘（671KB/413KB，2x 分辨率）→ 读图逐项验收（渐变头部/卡片描边/待办 checkbox+负责人 tag/页脚全部正确，rgba 半透明卡片在 html2canvas 下渲染无误）→ 复制图片经 PowerShell 剪贴板检查确认 1440×1634 PNG 真实入板。

## 坑

- **html2canvas 与现代 CSS 的兼容面**：它自己解析重绘 CSS，Chromium 能渲染 ≠ 它能截。`oklch()` 直接报错、`box-shadow` 静默丢弃。海报样式必须约束在 hex/rgba + linear-gradient 子集内。
- **缩放预览与全尺寸截图不能同实例**：CSS `zoom`/`transform` 影响布局盒，直接截预览元素会得到缩放/裁切产物。两实例（预览 zoom 份 + 离屏原尺寸份）是零风险解法。

## 边界（后续可扩）

- 主题固定 5 套内置，无自定义/无 VIP 概念（用户拍板）；转写全文不入海报（海报只承载纪要/要点/待办，逐字稿走导出与归档）。
- 复制图片依赖 WebView2 剪贴板权限（Wails 默认放行，本次真机已验）；失败有兜底提示改用保存。
- 海报高度随内容自适应（长纪要出长图），未做分页。
