# 迭代：听记 MCP 只读面（AI 工具连接）

- 日期：2026-10-12
- 状态：已完成（JSON-RPC 全流程真机冒烟通过）
- 关联：[`2026-10-12-听记对标钉钉逆向.md`](2026-10-12-听记对标钉钉逆向.md)（逆向发现钉钉本机 MCP 服务后的对齐切片）

## 目标 → 机制

| 目标 | 机制 |
| --- | --- |
| 员工的 AI 客户端（Cherry Studio/Claude 等）能读自己的听记 | Core 进程内置 MCP Streamable HTTP 端点 `/mcp`，4 个只读工具 |
| 安全：不随桌面 apiToken 扩散 | 独立配对令牌 `config.mcpToken`（自动生成、可吊销、恒时比较）；数据可见性 = 桌面端登录的知识服务账号 |
| 用户自助接入 | 设置页「AI 工具连接」卡片：地址+令牌一键复制，重新生成即吊销 |

## 实现

- **`internal/meetingsmcp`（新包）**：官方 SDK `github.com/modelcontextprotocol/go-sdk v0.2.0`。4 工具：`list_meetings`（id/标题/时长/发言人数/一句话摘要预览）、`get_meeting_summary`（章节纪要+要点+待办文本装配）、`get_meeting_transcript`（说话人+时间戳逐字稿）、`ask_meeting`（复用上一片的听记问答慢链路，5-30s）。刻意只读——无任何写入/删除工具；server instructions 引导「先 list 再取详情/提问」。
- **Core 挂载**：`/mcp`（自带 mcpToken 鉴权——不能套 auth 中间件，那认的是 apiToken）+ `/api/mcp/info`、`/api/mcp/regenerate`（apiToken 鉴权，桌面设置页用；regenerate 更新内存+落盘 config）。
- **config**：`mcpToken` 字段；旧配置 Load 时回填一次并落盘（重启不变，吊销=显式重生成）；defaultConfig 同步生成。
- **桌面级联**：desktop client `McpInfo/McpRegenerate` → App 绑定 `McpConnectionGet/McpConnectionRegenerate` → 设置页卡片（地址/令牌复制、重新生成双击确认）。

## 验证

- go build/test 全量绿（config 迁移补 `TestLoadMigratesMissingMCPToken`：回填+重启稳定；round-trip fixture 补新字段）；vue-tsc/vite/wails build 绿。
- **JSON-RPC 全流程冒烟**（Python 直连 19079/mcp）：坏令牌 401 → initialize（协议 2025-03-26、SDK 下发 Mcp-Session-Id）→ tools/list 4 工具 → `list_meetings` 真实 3 条记录带摘要预览 → `get_meeting_summary` 周会模板章节全文 → `ask_meeting`「最紧急的待办是谁负责」返回准确答案并引用说话人原话 → 不存在 id 返回 `isError` +「会议不存在」。
- 响应格式注意：SDK 默认以 `text/event-stream` 返回（SSE `data:` 行），冒烟脚本需按 Content-Type 分流解析——真实客户端由 SDK 层处理，无感。

## 坑

- **wails build 不重编 core（再次踩）**：本轮 `/api/mcp/info` 404 即因此——cp 了旧 core。桌面端改 Core 代码后必须 `go build -o build/bin/easyshare-core.exe ./cmd/core`。
- **Go nil 切片 → JSON null**：`history: null` 被 pydantic 拒收（缺省值只兜缺失字段不兜显式 null）。Go 侧 nil 归一空列表 + Python 侧 `list[T] | None` 双向防御。

## 边界与后续

- 会话无独立身份：MCP 令牌等价于「桌面端当前登录用户」的听记读权限，用户切换知识服务账号后可见范围跟随变化（文档已注明）。多账号细粒度授权（每客户端独立令牌+审计）后置。
- 无 server-initiated SSE 推送（SDK handler 自理 GET 流）；Stdio 传输不做（本地 HTTP 足够）。
- 同一骨架可平移：知识问答/文件/待办的 MCP 化只需换工具集。
