# EasyShare 权限闭环完善

## 用户问题
- 企业权限三层已实现，但普通文件管理员缺成员管理入口；知识检索仍按入库时 owner/部门快照，未消费控制面文件成员角色，文件撤权与问答可见性不一致。

## 目标
- 文件授权/撤权在知识问答、文档清单、阅读和原件访问使用一致的实时权限；仅查看可阅读但不可下载原件。
- 普通上传者/manage 成员可从网盘管理文件成员，非管理成员不能调用授权或成员搜索绕过权限。
- 旧链接与权限快照不构成控制面授权失败时的放行退路。

## 非目标
- 水印、防复制、逐动作 ACL 扩展、公司服务器部署、提交推送。
- 已下载到用户磁盘的正文无法远程收回；不承诺阻止截图或复制可阅读内容。

## 设计决策
- 遵循 ADR-0007：Java 控制面是文件权限权威，Python 仅消费裁决，不建立第二套角色真相。
- 查询/阅读按请求实时获取权限，不长期缓存授权结果；控制面不可用或旧版本缺接口时对受控文件拒绝放行。
- 复用现有文件成员服务与前端设计 token，成员搜索只返回授权所需的最小标识与展示字段。
- 绑定由控制面核验文件 ID/预期版本、配置 bucket、真实源摘要/大小；知识 ID 使用独立 `drive-` 域，不能接受客户端自报归属或任意绑定。
- 显式「加入知识库」是本片真实入口，不是自动索引；在入队前冻结源正文，处理与原件访问共用快照。旧受管文档仅摘要/大小与可信来源一致时迁移，不一致重新入库。
- 仅查看可检索/阅读但不可下载原件；`can_download` 串行贯通 Python→Go→Wails→前端，缺字段不默认展示下载。
- 同一共享空间的有效账号/部门才可新增授权；停用/范围外既有行可原样保留或移除，自己的用户行只读且整组保存剔除，服务端保留。共享列表下发四档有效角色，文件/版本/主体 ID 全字符串。
- 新共享子视图保留个人盘原功能，不复用个人盘 URL/挂载/分享错误通路；共享暂无安全原件预览，read 的已入库内容从「知识→文档」阅读。

## 兼容与迁移
- 不新增客户端静态存储凭据，不改 Core 监听范围。
- Go 导出方法变化必须重生成 Wails 绑定并同步前端类型/服务。
- 文件权限与知识文档稳定映射的迁移策略实现后记录；不将未关联知识文档误认为云盘文件。

## 发布与回滚
- 本轮不发版、不部署。更新顺序：控制面（现有权限 DDL＋新增知识裁决接口）→知识服务→桌面端；Python 任务库自动补来源关联列，无新增控制面 DDL。
- 回退旧控制面但保留新知识服务会关闭受管访问；不得把失败改为按旧权限快照放行。
- 验证产物为独立文件名，不覆盖/终止用户正在运行的安装版；本轮不运行 NSIS 全量流水线。
