# 迭代记录 — 会议听记：录音 → 转写 → 说话人 → AI 总结（2026-10-12，用户直配）

> 触发：用户提出对标钉钉「听记」（录音、说的话、发言人、总结）。当日完成调研与用户对齐
> （技术栈选型、采集层双平台方案、路线利弊），用户拍板「实现下吧」。

## 背景与目标

对标钉钉听记四能力，本片一次交付全链路（事后转写形态，非实时上屏）：

1. **录音采集**：桌面端会议录音（麦克风）
2. **语音转文字**：中文 ASR，事后批量转写
3. **说话人分离**：区分「说话人 1/2/3」，前端可改名（质量不达标时降级为无标签转写）
4. **AI 总结**：纪要 / 要点 / 待办三项结构化输出

与钉钉的差异点：转写与总结沉淀在**知识服务**侧，会议纪要后续可归档进知识库被问答引用
（私有知识服务器定位的天然协同，本片预留、量力实现）。

## 调研结论（方案依据，2026-10-12）

- **ASR 栈**：FunASR 开源全家桶（paraformer-large 转写 + fsmn-vad 端点 + ct-punc 标点 +
  cam++ 声纹聚类），中文第一梯队、CPU 可跑、私有部署友好；框架 MIT、模型权重按 ModelScope
  页面许可商用（下载时逐模型核对）。已知风险：cam++ 聚类在重叠语音/多人场景可能错并，
  GitHub issue 高频问题，需真实会议音频验收。
- **采集层**：Wails v2.14 **Windows 侧已默认放行全部 WebView2 权限**
  （`frontend.go:612` `SetGlobalPermission(CoreWebView2PermissionStateAllow)`，源码证实）——
  前端 getUserMedia 开箱即用，无需 Go 原生采集（malgo cgo 方案否决，避免 Windows 构建引入
  CGO）。macOS 侧 Wails v2 未实现 WKUIDelegate 媒体权限代理（WailsContext 未实现
  `requestMediaCapturePermission`）→ 本片以 objc category 补齐 + Info.plist 加
  `NSMicrophoneUsageDescription`，编译由 CI 把关，真机验证延后（同剪切板插件 darwin 先例）。
- **云 API 路线否决**：按小时计费 + 录音出内网，与私有部署定位冲突；留作远期可插拔 provider。

## 架构与数据流

```text
前端录音（getUserMedia + AudioWorklet → 16k 单声道 WAV，Int16 PCM）
  │  同源 fetch POST /kapi/meetings/transcribe（大文件走 blob，不经 Wails 绑定 JSON）
  ▼
桌面进程 assetserver Middleware 接管 /kapi/meetings/*（流转发）
  │  ⚠️ 必须在 Middleware 阶段接管：dev 下 Vite SPA fallback 会吞未知路径，
  │  fallback Handler 永远收不到（appplugin.go 既有结论，插件路由同款）
  ▼
desktop.Client → Core POST /api/knowledge/meetings/transcribe（apiToken 鉴权）
  ▼
knowledge.Client multipart → 知识服务 POST /meetings/transcribe
  ▼
异步 job：FunASR 转写+说话人 → LLM 总结（复用既有 llm 链路）→ 落盘
前端轮询 GET /meetings/{id} 至 completed
```

- 知识服务新增 `/meetings` API：transcribe（上传，异步）/ list / get / delete / rename-speaker；
  鉴权与 owner 可见性照 2b/2c 模式；`/health` 声明 asr 可用性（照 OCR 模式）。
- FunASR 为**可选重依赖**：`requirements-asr.txt` 单列（同 requirements-ocr.txt 先例），
  `ASR_ENABLED` 默认关，懒加载不拖累无 ASR 部署的启动。
- 存储：知识服务 `data/meetings/{id}.wav + {id}.json`（元数据/分段/总结）。

## 实现清单

**知识服务（Python）**
- `app/meetings/`（新包）：`engine.py`（FunASR 懒加载单例：paraformer-zh + fsmn-vad + ct-punc + cam++，发言轮次合并、纯标点碎片过滤、transcript 渲染）/ `store.py`（`data/meetings/{id}.wav + .json` 平面存储）/ `summarizer.py`（OpenAI 兼容 LLM 出 JSON {minutes,key_points,todos}，>45k 字 map-reduce，失败降级为有转写无总结）/ `service.py`（单 worker 串行执行转写+总结，异步落盘状态机）/ `routes.py`（6 端点）
- 端点：`POST /meetings/transcribe`（multipart 流式落盘，202 受理）/ `GET /meetings`（owner 过滤列表）/ `GET|DELETE /meetings/{id}` / `PATCH /meetings/{id}/speakers`（改名）/ `GET /meetings/{id}/audio`（FileResponse 回放）/ `POST /meetings/{id}/archive`（纪要+转写 markdown 入知识库，owner 随会议）
- 装配：`ASR_ENABLED` 默认关（可选依赖 `requirements-asr.txt` 单列，照 OCR 先例）；AppServices 加 `meetings` 可选组件；`/health` 增 `asr` 能力声明；`/meetings` 进 auth 保护前缀；`__init__` 刻意不导出 routes 防循环导入

**Go（Core + 桌面端）**
- `internal/knowledge/client.go`：Meeting/Segment/Summary/ArchiveResult 类型 + Meetings/Meeting/Delete/Rename/Archive（JSON）+ `UploadMeeting`（multipart 流式转发）/ `StreamMeetingAudio`（音频流透传）
- `internal/api`：7 条 `/api/knowledge/meetings/*` 路由；上传/音频解除 30s 写超时（10min 上下文兜底）；`knowledgeSession` 统一未登录守卫
- `internal/desktop/client.go`：镜像方法集；上传/音频走 `slowHTTP` 无客户端超时
- `appmeetings.go`（新）：App 绑定 5 个（MeetingsList/MeetingDetail/MeetingRemove/MeetingSpeakerRename/MeetingArchiveToKnowledge）+ `serveMeetingGateway`（`/kapi/meetings/transcribe` 上传与 `{id}/audio` 回放的同源流式网关），经 `pluginAssetMiddleware` 接管（dev 下 Vite 会吞 fallback Handler，必须 Middleware 阶段拦截）

**前端（Vue 3）**
- `services/recorder.ts`（新）：getUserMedia + AudioWorklet（blob URL 注入，ScriptProcessor 兜底）→ 16k 单声道 Int16 → WAV 编码；线性插值降采样；RMS 电平节流回调
- `components/MeetingsPanel.vue`（新）：录音卡（主题输入/计时/电平条/完成与取消）→ 轮询详情至完成；详情卡（audio 播放器 + 纪要/要点/待办 + 发言人行内改名 + 归档/两段式删除）；未登录引导去「知识」页
- 侧边栏新增「会议听记」；样式段追加 style.css；类型入 types/core.ts，封装入 core.ts

**macOS**
- `build/darwin/Info.plist`：`NSMicrophoneUsageDescription`
- `meetings_capture_darwin.m`（新）：WailsContext category 补 WKUIDelegate 媒体权限代理（麦克风放行、摄像头/屏幕共享拒绝）；Windows 侧 Wails v2.14 已默认放行（`frontend.go:612` SetGlobalPermission 源码证实），无需处理

## 环境备注（本机）

- 本机知识服务现以 **venv Python + `ASR_ENABLED=true`** 运行（原为系统 Python 直启，缺 funasr）；FunASR 模型已缓存 `~/.cache/modelscope`（约 1.5GB）

## 边界与不做清单

- **实时上屏（边说边出字）不做**：流式 2pass + WebSocket 通道，量级翻倍，后续切片
- **系统声音内录不做**：macOS 无公开 loopback API（需虚拟声卡驱动）；Windows WASAPI
  loopback 为后续 Windows-only 加分项
- **macOS 录音真机验证延后**：category + plist 编译 CI 把关，TCC 弹窗与 CoreAudio 行为待 Mac
- **说话人声纹注册（绑定真人）不做**：输出「说话人 N」+ 前端改名即达标
- 会议音频不进对象存储/RustFS（本地 data 目录即可），不参与配额
