## 修复清单

1. **侧边栏插件条目错位**：`.nav-item > span` 计数徽章规则（`margin-left:auto`）误伤了插件
   条目的图标/内置徽标 span——图标被推右且推移量随尾部内容变化。修：徽章规则收窄为
   `.nav-item > .nav-count`（模板补类名），`.nav-update-dot` 自行补 `margin-left:auto`。
2. **待办与周报弹窗进页面空着常驻且关不掉**：`.sheet { display:flex }` 作者样式压过
   `[hidden]` 的 UA 默认 `display:none`。修：补 `.sheet[hidden] { display:none }`。
3. **商城已装插件可被「重新安装」静默降级**：安装按钮无版本方向感（本地 2.0.2 > 商城
   2.0.1 仍显示重装）。修：前端 `compareVersions` + `localNewer`——本地更新时隐藏按钮并
   展示「本地 v*x* 已比商城新」；版本相等保留「重新安装」作修复通道。
4. **商城更新报错 `Cannot read properties of null (reading 'length')`**：Go 预览结果
   `NewPermissions` 零值 nil 序列化为 `null`，前端直取 `.length`。修：Go 侧
   `diffNewPermissions` 返回空数组 + 前端 `?? []` 兜底。
